## 📖 Présentation

**Avant de Poster** est une application web éducative destinée principalement aux jeunes afin de les sensibiliser aux risques liés à leur utilisation quotidienne d'Internet.

Une photo, une vidéo, un message ou une conversation peuvent révéler beaucoup plus d'informations personnelles qu'on ne l'imagine.

L'objectif du projet est d'apprendre aux utilisateurs à prendre quelques secondes de réflexion avant de :

* 📸 publier une photo ;
* 🎥 partager une vidéo ;
* 💬 répondre à une personne inconnue ;
* 📍 partager sa localisation ;
* 🔐 communiquer des informations personnelles ;
* 👤 faire confiance à une personne rencontrée en ligne.

Le projet ne cherche pas à faire peur aux jeunes.

Il cherche au contraire à leur donner **les bons réflexes pour devenir plus autonomes et plus prudents sur Internet.**

> **Avant de poster. Avant d'envoyer. Avant de répondre.**

---

## 🎯 Objectifs du projet

Le projet repose sur plusieurs objectifs pédagogiques :

### 🔐 Protéger sa vie privée

Apprendre à identifier les informations personnelles qui peuvent être visibles ou déduites à partir d'une publication.

Exemples :

* adresse ;
* numéro de téléphone ;
* école ;
* lieu de travail ;
* localisation ;
* plaque d'immatriculation ;
* documents personnels ;
* informations présentes dans les métadonnées d'une photo.

### 📸 Réfléchir avant de publier

<img width="1898" height="917" alt="20260831112503" src="https://github.com/user-attachments/assets/d6625768-a93f-4c2e-92bc-69b0e50c894b" />


Une image peut contenir beaucoup plus d'informations qu'elle n'en a l'air.

L'application permet notamment de sensibiliser l'utilisateur aux :

* métadonnées EXIF ;
* coordonnées GPS ;
* informations sur l'appareil ;
* dates de prise de vue ;
* éléments visibles dans l'arrière-plan ;
* plaques d'immatriculation ;
* documents ;
* écrans ;
* informations personnelles visibles.

### 💬 Reconnaître les comportements suspects

Les conversations avec des inconnus peuvent parfois contenir différents signaux d'alerte :

* demandes d'informations personnelles ;
* demande de photos ;
* pression ;
* manipulation ;
* demande de secret ;
* tentative d'isolement ;
* proposition de rendez-vous ;
* comportement insistant.

L'objectif n'est pas de déterminer automatiquement si une personne est « dangereuse », mais d'apprendre à l'utilisateur à **identifier les situations qui doivent l'inciter à être prudent.**

### 🆘 Savoir demander de l'aide

Le projet rappelle également une règle importante :

> Tu n'es jamais obligé de gérer seul une situation qui te met mal à l'aise.

L'utilisateur est encouragé à :

* arrêter une conversation ;
* bloquer un compte ;
* signaler un utilisateur ;
* conserver des preuves lorsque cela est nécessaire ;
* parler à un adulte ou à une personne de confiance.

# 🚀 Fonctionnalités

## 🎮 Quiz

Le quiz propose des situations inspirées de situations pouvant être rencontrées sur Internet.

L'utilisateur doit choisir la réaction qui lui semble la plus appropriée.

Après chaque réponse, l'application explique :

* pourquoi la réponse est correcte ;
* pourquoi une autre réaction peut être risquée ;
* quel réflexe retenir.

L'objectif est d'apprendre **en faisant**, plutôt que simplement lire une liste de recommandations.

---

## 📸 Analyse des photos

La section Photos permet de vérifier les informations potentiellement sensibles présentes dans une image.

L'analyse peut notamment rechercher :

### Métadonnées

* 📍 GPS ;
* 📱 appareil utilisé ;
* 📅 date de prise de vue.

### Informations visibles

* 🚗 plaques d'immatriculation ;
* 📄 documents ;
* 🏫 informations liées à une école ;
* 📍 informations de localisation ;
* 📱 écrans ;
* 🎫 billets et QR codes ;
* 🔐 informations personnelles.

L'application fournit ensuite un niveau de risque et des recommandations permettant à l'utilisateur de comprendre ce qu'il devrait vérifier avant de publier la photo.

---

## 🎥 Sensibilisation aux vidéos

Les vidéos peuvent également révéler des informations personnelles.

Même lorsqu'une personne pense ne rien montrer de sensible, une vidéo peut contenir :

* une adresse ;
* une rue ;
* une école ;
* une plaque ;
* un écran ;
* une conversation ;
* une personne présente à l'arrière-plan ;
* des informations permettant de déterminer une localisation.

Le projet a donc pour objectif de sensibiliser l'utilisateur au fait qu'il faut regarder **l'ensemble du contenu**, et pas uniquement le sujet principal de la vidéo.

---

## 💬 Conversations

La section Conversations utilise une approche interactive.

L'utilisateur découvre différentes situations :

> « Un inconnu te demande ton adresse. »

> « Quelqu'un te demande de garder votre conversation secrète. »

> « Une personne rencontrée en ligne te demande une photo. »

> « Quelqu'un te propose un rendez-vous et te demande de ne prévenir personne. »

L'utilisateur choisit ensuite ce qu'il ferait.

L'application explique alors :

* le bon réflexe ;
* les signaux d'alerte ;
* les risques potentiels ;
* ce qu'il pourrait faire dans cette situation.

Cette approche transforme la sensibilisation en **expérience interactive**.

# 🔒 Confidentialité

La protection des utilisateurs est un élément central du projet.

L'application doit éviter de conserver inutilement :

* les photos envoyées ;
* les conversations analysées ;
* les informations personnelles ;
* les données permettant d'identifier les utilisateurs.

Les données nécessaires au fonctionnement de l'application doivent être traitées avec le minimum de conservation possible.

La clé API Groq doit rester exclusivement côté serveur.

---

# ⚠️ Limites de l'intelligence artificielle

L'analyse IA est un **outil d'aide à la sensibilisation**, et non un système capable de déterminer avec certitude les intentions d'une personne.

Une IA peut :

* se tromper ;
* ne pas détecter un élément ;
* interpréter incorrectement une situation ;
* considérer une situation comme préoccupante alors qu'elle ne l'est pas.

Les résultats doivent donc être présentés comme des **indications pédagogiques**.

En cas de situation réellement inquiétante, l'utilisateur doit être encouragé à en parler à une personne de confiance ou à un professionnel compétent.
